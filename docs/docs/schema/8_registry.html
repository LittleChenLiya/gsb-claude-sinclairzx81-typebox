Schema.Registry

An explicit, sealed collection for schema reference compilation. Schemas are registered by $id, all $ref values are bound up front, and validators are only generated after binding succeeds.

Overview

The registry makes reference compilation explicit:

  • A duplicate $id with a different definition is rejected; an identical re-registration is a no-op.
  • A $ref only resolves against documents in the same collection or mappings explicitly authorized with External(...). There is no process global cache, so two registries that happen to use the same $id can never leak into one another.
  • Recursive references (self or mutual) are allowed and are followed lazily at validation time, so binding terminates without infinite expansion.
  • Registered documents are deep cloned on entry. Mutating the caller object after registration never affects the sealed collection.
  • Compile(id) runs only after the document is fully bound; TryCompile(id) returns undefined for an unknown id or an unresolvable reference.
  • The default Schema.Compile(schema) entry point is unchanged.

Example

import Schema from 'typebox/schema'

const Node = {
  $id: 'Node',
  type: 'object',
  properties: {
    id: { type: 'number' },
    children: { type: 'array', items: { $ref: 'Node' } } // self reference
  },
  required: ['id']
}

const TreeMeta = {
  $id: 'TreeMeta',
  type: 'object',
  properties: { owner: { $ref: 'Tree' } }                // mutual reference
}

const Tree = {
  $id: 'Tree',
  type: 'object',
  properties: {
    root: { $ref: 'Node' },                               // cross document
    meta: { $ref: 'TreeMeta' }                            // cross document
  }
}

const registry = new Schema.XRegistry()
registry.Register(Node, 'schemas/node.json')               // source is retained
registry.Register(TreeMeta, 'schemas/tree-meta.json')
registry.Register(Tree, 'schemas/tree.json')

registry.Bind()                                            // throws on unknown ref

const validator = registry.Compile('Tree')
const ok = validator.Check({
  root: { id: 1, children: [{ id: 2 }] },
  meta: { name: 'forest', owner: { root: { id: 9 } } }
})

Unknown References

Binding reports every reference that could not be resolved. No validator is produced for such a document.

const registry = new Schema.XRegistry([{
  $id: 'B',
  properties: { x: { $ref: 'Missing' } }
}])

const result = registry.Bind({ throw: false })
result.ok            // false
result.unresolved    // [{ id: 'B', ref: 'Missing' }]

registry.TryCompile('B')   // undefined: unknown ref, no validator

External Mappings

References to documents outside the collection resolve only through mappings authorized explicitly with External.

const remote = new Schema.XRegistry([{
  $id: 'https://example.com/remote',
  $defs: { Point: { type: 'object', properties: { x: { type: 'number' } } } }
}])

const local = new Schema.XRegistry([{
  $id: 'Local',
  properties: { p: { $ref: 'https://example.com/remote#/$defs/Point' } }
}])

local.External('remote-set', remote)                      // authorize
local.Bind()                                             // ok

Source Index

Index() retains the schema index: every registered $id paired with the source label and sealed schema.

for (const entry of registry.Index()) {
  entry.id        // 'Node'
  entry.source    // 'schemas/node.json'
  entry.schema    // sealed deep clone
}
